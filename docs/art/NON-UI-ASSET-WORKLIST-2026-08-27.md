> 기준 계약: 원격 `claude/read-this-yyycmm`의 최신 `ASSETS.md`와 현재 A타입 신체 블루프린트.
> 제외: 룰렛·버튼·화폐 표시·장식 프레임 등 UI, 선택 프로필 초상.

## 확정 규칙

- 일꾼은 `가게별 세트 × A~D 무늬 × 앞치마 1~3단` 완성형이다. 점장·직원 이미지를 따로 만들지 않는다.
- 이동 원화는 `↘ side`와 `↗ back`만 만들고 반대 방향은 코드가 좌우 반전한다.
- 같은 가게 A~D는 눈·귀·몸통·발·접지선이 A 기준판과 2px 안에서 같아야 한다.
- 손에 드는 도구는 넣지 않는다. 가게·등급은 앞치마와 큰 복장 색면으로 구분한다.
- 물건 승급은 테두리나 광효과가 아니라 재료·마감 자체의 변화로 표현한다.
- 한국풍 생활상과 기존 갈색 색연필·크레용 외곽선을 유지한다.

- [x] 필방 계산대: `godot/art/counters/brush.png` — 기존 필방 좌판의 한지 상판·나무색을 이어받음
- [x] 지물포 계산대: `godot/art/counters/paper.png` — 한지 미닫이 전면으로 필방의 서랍형과 구분
- [x] 옹기점 계산대: `godot/art/counters/pot.png` — 황토판과 낮은 벽돌띠로 빈 상판에서도 옹기점이 읽힘
- [x] 약재상 계산대: `godot/art/counters/herb.png` — 넓은 약장 서랍 3×2로 작은 화면에서도 업종을 구분

## P2 · 콘셉트 승인 뒤 제작

- [ ] 필방부터 나전방까지 가게별 일꾼 세트. 한 가게의 1단 A타입 두 방향을 먼저 승인받고 24장으로 확장한다.
- [ ] 점장 카드 15장과 선택 승급 카드 30장. 해당 가게 일꾼 콘셉트가 먼저 확정되어야 한다.
- [ ] 손님 정면·뒷모습 60장. 기존 옆모습과 같은 개체·등급 톤을 유지하는 시험판부터 만든다.
- [ ] 가게별 풀무·가마 14장, 매대 5장, 선택 계산대 10장. 가게 콘셉트와 물건 실루엣 확정 뒤 제작한다.
