# INTERACTION-ITEMS-BATCH-01-P01

## 목적

필드 상호작용 3종과 룰렛 바늘을 채우고, 물건 80종 제작에 사용할 첫 기준 에셋으로 대장간 곡괭이를 시험한다.

## 공통 기준

- 승인된 `BP-V0.1-P01`의 따뜻한 흙·목재·숯색 팔레트와 손으로 그린 재료감을 따른다.
- 작은 모바일 화면에서 먼저 읽히는 굵고 단순한 실루엣을 사용한다.
- 캐릭터·물건 하나만 분리해 그리고 배경, 바닥, 글자, UI, 워터마크, 테두리는 넣지 않는다.
- 원근 수렴이나 아이소메트릭 격자 없이 거의 정면 또는 얕은 3/4 방향으로 그린다.
- 여러 프레임은 만들지 않는다. 이동·들썩임·회전·도망·룰렛 진동은 Godot 코드가 한 장을 움직여 표현한다.

## 생성 대상

1. `ui/needle.png` — 황동 원형 축, 짙은 목재 몸통, 아래를 가리키는 넓은 적색 삼각 촉. `64×96`.
2. `pests/rat.png` — 오른쪽으로 낮게 달리는 갈색 들쥐. 긴 꼬리와 짧은 다리. `128×128`.
3. `pests/crow.png` — 오른쪽으로 날며 부리에 엽전 하나를 문 검은 까마귀. `128×128`.
4. `pests/dog.png` — 마을을 지키는 갈색 삽살개. 풍성한 털과 안정적인 앉은 자세. `128×128`.
5. `items/pick.png` — 조선 서민 마을의 대장간에서 만든 철 곡괭이와 나무 자루. `128×224`.

## Hypothesis

- 쥐와 까마귀는 이동 방향이 그림에 이미 들어 있으므로 코드의 수평 이동과 작은 들썩임만으로 행동이 읽힌다.
- 삽살개는 앉은 자세 한 장을 작게 흔들거나 짧게 튕기는 것만으로 경비 역할을 표현할 수 있다.
- 룰렛 바늘은 별도 프레임 없이 회전축을 기준으로 코드가 진동시킨다.
- 물건은 캐릭터와 합성하지 않고 독립 PNG로 만들면 상점 카드와 점장 손 오버레이에 함께 재사용할 수 있다.

## 제외

- 쥐·까마귀·개에 옷, 모자, 무기, 인간 손을 붙이지 않는다.
- 까마귀 주변에 동전 여러 개나 속도선·먼지 효과를 넣지 않는다.
- 삽살개를 공격 자세나 위협적인 맹견으로 만들지 않는다.
- 곡괭이에 불꽃, 광채, 마법 등급 효과, 받침대를 넣지 않는다.

## 출력 후 처리

- 마스터 생성본은 `docs/art/generated/` 아래에 보존한다.
- 실제 투명 배경을 복구한 게임용 PNG를 `godot/art/` 아래 정확한 계약 경로에 둔다.
- 다섯 결과는 [interaction-items-batch-01.png](../qa/interaction-items-batch-01.png)에서 함께 축소 검수한다.
- 사용자 승인 전 상태는 모두 `Generated / 초안`이다.
