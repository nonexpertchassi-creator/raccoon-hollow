# GUEST-CARDS-TIER4-BATCH-03-P01

## 목적

소·호랑이·참새·개구리·두더지의 3단 개체·자세·계절·장터 장소를 유지하며, 논·산길·곡식마당·수로·텃밭의 연결된 기반시설로 4단 최종 성장을 시험한다.

## Hypothesis 적용

- `16~20성 / 4단 = 장날의 오래된 벗 → 함께 지킨 풍경`.
- 동물이나 좌판을 장식하지 않고 생활권 전체의 길·담·배수·물길·경작지 연결만 확장한다.
- 큰 동물과 작은 동물 모두 기존 실루엣과 빈 공간을 우선한다.

## 대상과 장면

- `ox-4`: 노을 논마을, 여러 논을 잇는 관개수로·온전한 둑·마을집과 이어진 넓은 길.
- `tiger-4`: 산비탈 마을, 연속된 돌계단·옹벽·난간·열린 고개와 연결된 지붕.
- `sparrow-4`: 곡식 건조마당, 이어진 처마와 담·쓸린 통로·마른 배수 경계·정돈된 저장.
- `frog-4`: 논물길, 여러 논으로 흐르는 맑은 수로·온전한 징검돌·작업대와 집길 연결.
- `mole-4`: 봄 텃밭, 구획된 이랑·작은 관개골·열린 밭문·집과 이어지는 보행로.
