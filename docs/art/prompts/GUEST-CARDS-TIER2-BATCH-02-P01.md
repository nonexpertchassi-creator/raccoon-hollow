# GUEST-CARDS-TIER2-BATCH-02-P01

## 목적

사슴·멧돼지·곰·거북·두루미의 2단 카드로, 서로 다른 계절과 등급에서도 ‘같은 개체 + 수선된 생활 공간’이라는 성장 규칙이 유지되는지 시험한다.

## 공통 기준

- 각 1단 마스터의 종·얼굴·무늬·몸 비율·자연 자세·계절을 유지한다.
- `512×768`, 2:3 세로, 약 7% 안전 여백, 한지 질감과 수채/과슈 밀도 유지.
- 2단은 의상·마법·등급광 없이 정돈된 생활 공간과 복구된 구조물만 늘린다.
- 카드 프레임·별·글자·등급색·UI 없음.

## 장면

| 파일 | 2단 변화 |
|---|---|
| `deer-2.png` | 수선된 돌담과 목문, 쓸어 둔 단풍과 묶은 멍석 |
| `boar-2.png` | 묶어 세운 볏단, 손본 작업막, 광주리와 멍석이 있는 추수마당 |
| `bear-2.png` | 눈을 쓸어 낸 길, 수선된 기와와 돌담, 장작·옹기·따뜻한 창호 |
| `turtle-2.png` | 손본 정자와 디딤돌, 깨끗한 연못 가장자리와 작은 물길 |
| `crane-2.png` | 정돈된 갈대길, 수선된 둑·나무다리·정자와 따뜻한 일출 반사 |

## Hypothesis

- 귀함~영물도 2단에서는 광효과 없이 생활 공간의 완성도만 올려 3·4단 여지를 남길 수 있다.
- 1단의 계절을 유지하면 같은 손님의 시간 연속성이 강해진다.
