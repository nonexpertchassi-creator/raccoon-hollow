# ITEMS-RICECAKE-BATCH-14-P01

## 목적

송편·백설기·약식·화전·다식을 실제 판매 단위로 만들고, 떡집 안에서 반달·큰 네모·찰밥 사각·꽃 원·찍음 과자의 실루엣 차이를 검증한다.

## 생성 대상

1. `songpyeon.png` — 작은 옹기 접시에 담은 아이보리·쑥색·연분홍 반달 송편과 짧은 솔잎.
2. `baekseol.png` — 나무 받침 위의 큰 흰 백설기 한 덩이, 잘린 모서리와 대추채 세 조각.
3. `yaksik.png` — 밤·대추·잣이 박힌 짙은 갈색 찰밥 사각 세 조각.
4. `hwajeon.png` — 분홍 진달래꽃 한 송이씩 올린 납작한 원형 화전 다섯 장.
5. `dasik.png` — 팔각 나무판 위에 3×3으로 놓인 쑥색·미색·분홍 다식 아홉 개와 절제된 찍음 무늬.

## 공통 기준

- 한 판매 단위를 실제 투명 배경에 생성하고 `128×224` 캔버스 중앙에 둔다.
- 짙은 charcoal 외곽선, 따뜻한 흙빛 색면, 절제된 명암, 미세한 한지 질감을 사용한다.
- 다섯 품목은 장식색보다 반달·큰 입방체·거친 사각·납작한 원·작은 3×3 반복으로 구분한다.
- 백설기는 작은 떡 여러 개가 아니라 하나의 큰 흰 덩어리로 보이게 한다.
- 현대 포장·라벨·글자·금박·등급 효과·수저·UI·테두리·워터마크를 넣지 않는다.

## Hypothesis

- 같은 떡집 품목도 높이와 외곽 구조를 달리하면 `64×112` 표시 크기에서 서로 다른 상품으로 읽힌다.
- 꽃과 솔잎 같은 재료 표식은 작은 크기에서 종류를 돕되 장식품처럼 과장하지 않아도 충분하다.
- 다식의 3×3 반복은 개별 문양이 작아져도 다식판의 정돈된 인상을 남긴다.
