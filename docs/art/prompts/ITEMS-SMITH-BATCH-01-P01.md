# ITEMS-SMITH-BATCH-01-P01

## 목적

`ITEM-PICK-V0.1`을 첫 기준으로 삼아 대장간 기본 도구 다섯 종을 같은 모바일 물건 세트로 확장한다.

## 공통 생성 기준

- 대상: 낫, 호미, 도끼, 가위, 부엌칼.
- 물건 하나만 세로형 화면 중앙에 두고 실제 투명 배경으로 생성한다.
- 최종 계약은 `128×224`, 게임 표시 크기는 `64×112`다.
- 숯빛 무쇠와 따뜻한 황토갈색 나무를 큰 색면으로 나누고 짙은 charcoal 외곽선을 공유한다.
- 곡괭이와 비슷한 얕은 사선, 넉넉한 투명 여백, 손으로 그린 미세한 금속·목재 결을 사용한다.
- 캐릭터, 손, 받침대, 바닥, 그림자, 글자, 가격표, 등급 효과, UI, 테두리를 넣지 않는다.

## 대상별 실루엣

1. `sickle.png` — 크게 휘어진 낫날과 짧은 나무 손잡이.
2. `hoe.png` — 손잡이에 직각으로 꺾인 넓은 호미날.
3. `axe.png` — 쐐기형 도끼날과 긴 나무 자루.
4. `shears.png` — 닫힌 두 날과 큰 고리 손잡이가 보이는 무쇠 가위.
5. `knife.png` — 넓은 실용 칼날과 짧은 나무 자루의 부엌칼.

## Hypothesis

- 금속 도구는 철의 세부 광택보다 날·자루의 외곽 차이가 먼저 읽혀야 같은 세트로 보인다.
- 모든 원본을 독립 PNG로 만들면 물건 카드와 점장 판매 손 오버레이에 함께 쓸 수 있다.
- 폭이 다른 도구도 높이 기준으로 맞추면 세로 슬롯에서 가치와 크기가 과도하게 달라 보이지 않는다.

## 출력·검수

- 마스터는 `docs/art/generated/items/ITEM-<ID>-V0.1-master.png`에 보존한다.
- 게임용은 `godot/art/items/<id>.png`에 정확한 `128×224` RGBA로 둔다.
- [items-smith-batch-01.png](../qa/items-smith-batch-01.png)에서 다섯 장의 축·선·철색·나무색을 비교한다.
- 사용자 승인 전에는 모두 `Generated / 초안`이다.
