# GUEST-CARDS-TIER3-BATCH-02-P01

## 목적

사슴·멧돼지·곰·거북·두루미의 2단 개체·자세·계절·생활 장소를 유지하고, 각 장소에 맞는 장날의 쓰임을 배경 가장자리에 더한다.

## Hypothesis 적용

- `11~15성 / 3단 = 익숙한 단골 → 장날의 오래된 벗`.
- 열린 공간과 준비된 물건만으로 장날을 암시하고, 사람·추가 동물·의상·직업 자세는 넣지 않는다.
- 물건과 좌판은 동물보다 작고 화면 가장자리에 둔다.

## 대상과 장면

- `deer-3`: 단풍 돌담길, 열린 대문, 대추·버섯 광주리, 멍석·장작 좌판.
- `boar-3`: 추수 마당, 곡식자루·채반·되·볏단 손수레.
- `bear-3`: 눈길 처마, 밤·곶감 광주리, 곡식자루·장작·빈 썰매 손수레.
- `turtle-3`: 연못 정자, 접은 멍석, 물장독과 찻잔, 연밥·떡 채반.
- `crane-3`: 나루와 정자, 포장 음식 광주리·갈대 묶음·빈 손수레.

## 출력과 판정

- 마스터: `docs/art/generated/cards/CARD-<ID>-T3-V0.1-master.png`
- 런타임: `godot/art/cards/<id>-3.png`
- QA: `docs/art/qa/guest-cards-tier3-batch-02.png`
- 다섯 런타임 파일은 정확한 `512×768`이다.
