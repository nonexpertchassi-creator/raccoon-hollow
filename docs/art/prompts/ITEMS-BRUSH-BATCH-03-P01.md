# ITEMS-BRUSH-BATCH-03-P01

## 목적

필방의 남은 연적·필통·서산·붓걸이·화첩을 채우고, 현대 문구나 중국 궁중 장식으로 흐르지 않는 조선 문방구 실루엣을 만든다.

## 형태 확인

- 한국민족문화대백과의 [문방구](https://encykorea.aks.ac.kr/Article/E0019480) 설명을 기준으로 연적은 먹 갈 물을 담는 그릇, 필통은 붓을 세워 꽂는 통, 필가는 붓을 걸거나 놓는 도구로 잡았다.
- 국립민속박물관 소장 [서산(書算)](https://artsandculture.google.com/asset/book-reading-counter-unknown/wwEh5bnDDnsXHg?hl=ko)은 종이 재질의 길고 좁은 독서 횟수 계수 도구다. 게임에서는 여러 종이 표식을 한 묶음으로 엮은 실루엣으로 단순화한다.

## 생성 대상

1. `waterp.png` — 위의 물 채움 구멍과 옆의 작은 물 나오는 구멍이 보이는 담청 백자 연적.
2. `brushpot.png` — 자주 쓰는 붓 몇 자루를 세워 둔 백자 필통.
3. `bookmk.png` — 한지 표식 여러 장을 갈색 끈으로 묶은 길고 좁은 서산.
4. `brushrk.png` — 네 개의 완만한 홈과 짧은 발을 가진 소박한 나무 붓걸이.
5. `album.png` — 남색 천 표지, 한지 책장, 간단한 선장 제본, 빈 제목지를 가진 닫힌 화첩.

## 공통 기준

- 한 물건만 실제 투명 배경에 생성하고 `128×224` 캔버스 중앙에 둔다.
- 실제 표시 크기 `64×112`에서 용도가 읽히도록 구멍·통·종이갈피·홈·제본을 큰 형태로 단순화한다.
- 짙은 charcoal 외곽선, 따뜻한 백자·대나무·한지·나무 색, 절제된 청화 한두 획만 사용한다.
- 문자·숫자·그림 속 그림·금박·붉은 칠·용무늬·긴 술·바닥·그림자·UI·테두리를 넣지 않는다.

## Hypothesis

- 낯선 서산은 종이 표식을 여러 장 분명히 나누고 끈으로 묶으면 게임 목록에서 ‘책 읽기 도구’로 학습할 수 있다.
- 필방은 화려한 장식보다 백자·대나무·먹·한지·나무의 재료 차이로 종류가 읽혀야 한다.
- 필통 속의 짧은 붓 자루는 용도를 설명하는 구성 요소이며, 별도 판매 물건 `brush.png`와 혼동하지 않도록 털끝은 크게 드러내지 않는다.
