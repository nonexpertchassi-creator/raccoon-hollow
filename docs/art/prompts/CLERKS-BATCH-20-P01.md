# CLERKS-BATCH-20-P01

## 목적

첫 묶음에서 정한 공용 얼굴·몸·짧은 앞치마·make/sell 자세를 유지하고, 지물포 쌍을 닫은 뒤 옹기점과 약재상의 두 포즈를 같은 최소 표식 체계로 확장한다.

## 생성 대상

1. `paper-sell.png` — 밝은 한지색 앞치마와 황갈색 단, 옆에 꽂은 작은 무지 종이 조각, 별도 판매 물건을 얹을 빈 양손.
2. `pot-make.png` — 탁한 황토색 앞치마와 적갈색 단, 내린 앞발의 작은 흙 얼룩.
3. `pot-sell.png` — 같은 황토색 앞치마·적갈색 단, 별도 판매 물건을 얹을 빈 양손.
4. `herb-make.png` — 탁한 쑥빛 앞치마와 미색 단, 옆끈의 작은 잎 두 장.
5. `herb-sell.png` — 같은 쑥빛 앞치마·미색 단·옆 잎, 별도 판매 물건을 얹을 빈 양손.

## 공통 기준

- `HERO-V0.3`와 첫 전용 점장 5장을 참조해 같은 한국 너구리 정체성·얼굴·털색·고리 없는 꼬리·몸 비율·포즈를 유지한다.
- 전신 옷·저고리·바지·큰 모자 없이 짧은 허리 앞치마만 사용한다.
- sell 포즈의 양손은 품목 PNG가 별도로 올라가도록 비운다.
- 실제 투명 배경의 `144×144`, 하단 발접점 정렬로 정리한다.
- 문자·UI·배경·업종 상품 더미·등급 효과·테두리·워터마크를 넣지 않는다.

## Hypothesis

- 한지색·황토색·쑥빛이라는 큰 색면만으로 이웃한 세 업종을 `72×72`에서 구분할 수 있다.
- make/sell 쌍은 업종 표식보다 팔 자세를 동일하게 유지할 때 판매 물건 오버레이를 재사용하기 쉽다.
- 손의 작은 얼룩과 옆 잎은 확대 화면의 보조 정보이며, 축소 화면에서 사라져도 실패가 아니다.
