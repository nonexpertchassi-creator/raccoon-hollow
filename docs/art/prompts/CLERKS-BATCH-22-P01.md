# CLERKS-BATCH-22-P01

## 목적

꼬치집 판매 포즈를 닫고 떡집·푸줏간 두 포즈를 만들어 가게 10곳 × make/sell 전용 점장 20장 초안을 완성한다.

## 생성 대상

1. `skewer-sell.png` — 먹색 앞치마와 적갈색 옆끈, 작은 그을음 밑단, 빈 양손.
2. `ricecake-make.png` — 따뜻한 아이보리 앞치마와 옅은 귀리색 단, 내린 앞발과 앞치마 모서리의 작은 쌀가루 자국.
3. `ricecake-sell.png` — 같은 아이보리 앞치마·귀리색 단·아주 작은 가루 자국, 깨끗하고 빈 양손.
4. `butcher-make.png` — 깊고 탁한 적갈색 가죽 앞치마와 어두운 갈색 단, 한쪽 앞발의 단순한 어두운 보호대.
5. `butcher-sell.png` — 같은 적갈색 가죽 앞치마·어두운 단·한쪽 보호대, 별도 판매 물건을 얹을 빈 양손.

## 공통 기준

- `HERO-V0.3`와 각 업종의 먼저 만든 자세를 참조해 같은 한국 너구리 얼굴·털색·몸 비율·고리 없는 꼬리·두 포즈를 유지한다.
- 전신 옷 없이 짧은 허리 앞치마만 사용한다.
- 손에 꼬치·떡·떡메·칼·고기·뼈를 들리지 않는다. 상품과 도구는 게임 코드가 별도 PNG로 합성한다.
- 푸줏간은 피·날붙이·공포 표현 없이 친근하고 깨끗하게 유지한다.
- sell 포즈의 양손은 판매 물건 오버레이를 위해 비운다.
- 실제 투명 배경의 `144×144`, 하단 발접점 정렬로 정리한다.
- 문자·UI·배경·등급 효과·테두리·워터마크를 넣지 않는다.

## Hypothesis

- 밝은 아이보리의 가루 자국과 깊은 적갈색 가죽만으로 떡집과 푸줏간을 직접 상품 기호 없이 구분할 수 있다.
- 보호대 방향의 작은 차이보다 얼굴·앞치마 큰 색면·make/sell 팔 방향이 축소 화면의 일관성에 더 중요하다.
- 전용 점장 20장은 공용 점장 폴백을 대체하되, 걷기·수면 그림은 공용 그림을 계속 재사용할 수 있다.
