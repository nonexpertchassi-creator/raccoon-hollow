# GUEST-CARDS-TIER1-BATCH-03-P01

## 목적

손님 카드 등급의 양끝인 흔함과 영물·신수를 한 묶음에서 비교해, 같은 화풍 안에서 장면의 크기와 여백만으로 위계를 벌린다.

## 공통 기준

- 기존 1단 카드의 2:3 구도, 7% 안전 여백, 한지 질감, 짙은 외곽선 유지
- 자연 동물의 정면 또는 3/4 정면 큰 배치
- 카드 프레임·등급색·별·글자·UI·광효과 없음

| 파일 | 등급·장면 |
