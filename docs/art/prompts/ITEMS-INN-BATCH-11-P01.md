# ITEMS-INN-BATCH-11-P01

## 목적

묵무침·청주·보쌈·법주·구절판으로 주막 8종을 마무리하고 술 세 종과 안주 세 종의 실루엣 중복을 막는다.

## 생성 대상

1. `muk.png` — 여섯 개의 반투명 갈색 묵 정육면체와 깻잎채.
2. `cheongju.png` — 짧은 주둥이·고리 손잡이의 미색 주전자와 맑은 청주 잔.
3. `bossam.png` — 배추잎 위 지방층 보이는 편육 다섯 점과 작은 장.
4. `beopju.png` — 미색 천으로 입을 묶은 넓은 황갈색 술항아리와 진한 술잔.
5. `gujeol.png` — 가운데 전병과 여덟 칸 채소채를 담은 팔각 목제 구절판.

## 공통 기준

- 한 판매 단위를 실제 투명 배경에 생성하고 `128×224` 캔버스 중앙에 둔다.
- 짙은 charcoal 외곽선, 따뜻한 흙빛 색면, 절제된 명암, 미세한 한지 질감을 사용한다.
- 청주는 미색 주전자와 맑은 술, 법주는 넓은 황갈색 항아리와 천 덮개로 막걸리·동동주와 구분한다.
- 구절판은 정확히 가운데 1칸과 둘레 8칸을 보여 주되 금박·검정/붉은 궁중 칠을 넣지 않는다.
- 쟁반·젓가락·문자·라벨·UI·테두리·워터마크를 넣지 않는다.

## Hypothesis

- 술의 색보다 용기의 병·주전자·항아리·넓은 사발 차이를 우선하면 작은 슬롯에서 중복이 줄어든다.
- 묵무침은 갈색 정육면체, 보쌈은 지방띠 편육, 구절판은 팔각 칸막이로 안주 실루엣이 분리된다.
- 구절판의 화려함은 재료색에만 두고 상자 장식은 소박한 목재로 제한하면 궁중풍 드리프트를 줄인다.
