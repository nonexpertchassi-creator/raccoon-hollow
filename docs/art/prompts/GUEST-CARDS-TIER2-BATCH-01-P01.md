# GUEST-CARDS-TIER2-BATCH-01-P01

## 목적

첫 5종의 2단(6~10성) 카드로, 같은 손님이 새 동물이나 의인화 캐릭터로 바뀌지 않으면서 ‘마을에 익숙해진 단골’로 성장하는 시각 규칙을 시험한다.

## 공통 생성 기준

- 각 1단 마스터를 직접 참조해 같은 개체의 종·얼굴·털/깃 무늬·몸 비율·자연 자세를 유지한다.
- 2:3 세로, 게임용 런타임 `512×768`, 가장자리 약 7% 안전 여백.
- 1단의 한국 동물 자연화와 한지 질감·수채/과슈 밀도를 유지한다.
- 2단의 변화는 의상·마법·등급광이 아니라 `외곽 → 정돈된 마을 안쪽`, `낡은 생활 공간 → 수선된 생활 공간`으로 만든다.
- 동물은 계속 자연 상태다. 옷·모자·장신구·인간 자세·말풍선·마법 효과 없음.
- 카드 프레임·등급색·별·글자·UI는 코드가 그리므로 이미지에 넣지 않는다.

## 카드별 장면

| 파일 | 1단에서 2단으로 바뀐 생활 장면 |
|---|---|
| `rabbit-2.png` | 수선된 돌담과 쓸린 봄길, 작은 빈 광주리와 새싹·흰 들꽃 |
| `magpie-2.png` | 정돈된 안뜰 돌담, 건강한 감나무와 가까워진 한지 창호 집 |
| `squirrel-2.png` | 같은 그루터기, 정돈된 도토리 광주리와 쓸어 모은 낙엽, 수선된 담장 |
| `badger-2.png` | 묶어 정리한 장작더미, 수선된 돌담, 따뜻하게 켜진 한지 창과 작은 포장 꾸러미 |
| `fox-2.png` | 열린 목문과 수선된 돌담, 쓸린 길, 따뜻한 창호와 정돈된 소나무 |

## Hypothesis

- 1단과 같은 동물 정체성을 유지한 채 배경 회복과 생활소품만 늘려도 6~10성의 성장감이 생긴다.
- 2단은 ‘화려함’보다 ‘마을과 가까워짐’이 먼저여야 3·4단의 확장 여지가 남는다.
- 작은 광주리·꾸러미는 손님이 착용하거나 드는 장식이 아니라 마을 생활 반경의 증거로만 사용한다.
