# ITEMS-POT-BATCH-06-P01

## 목적

옹기점의 청자·시루·술병·다기·향로를 서로 다른 재료와 용도 실루엣으로 확장한다.

## 생성 대상

1. `celad.png` — 작은 입, 높은 어깨, 좁은 굽의 옅은 비취색 청자 매병.
2. `steamr.png` — 열린 위에서 구멍 난 바닥이 보이는 갈색 질그릇 시루.
3. `bottle.png` — 긴 목, 배 모양 몸, 한 번의 회갈색 붓자국을 가진 백자 술병.
4. `teaset.png` — 분청빛 작은 주전자 하나와 찻잔 두 개를 붙여 놓은 다기 묶음.
5. `censer.png` — 구멍 난 낮은 뚜껑, 세 발, 작은 고리 귀를 가진 노쇠한 금속 향로.

## 공통 기준

- 한 판매 단위를 실제 투명 배경에 생성하고 `128×224` 캔버스 중앙에 둔다.
- 비취색 유약·갈색 흙·백자·분청·어두운 금속을 큰 재료 색면으로 구분한다.
- 짙은 charcoal 외곽선, 절제된 명암, 미세한 유약·흙·금속 질감을 사용한다.
- 용·봉황·사자·연꽃·금박·궁전 장식·문자·배경·바닥·그림자·UI·테두리를 넣지 않는다.

## Hypothesis

- 도자기류는 색만 바꾸지 않고 입·목·몸·구멍·잔의 유무로 용도를 먼저 읽혀야 한다.
- 다기는 여러 물체지만 주전자와 두 잔을 서로 붙여 하나의 삼각형 판매 단위로 묶으면 슬롯에서 산만하지 않다.
- 향로는 뚜껑 구멍과 세 발만으로 용도가 읽히며 연기 프레임은 필요하지 않다.
- 청자 유약의 작은 균열은 원화에만 남고 `64×112`에서는 비취색 덩어리로 정리되어야 한다.
