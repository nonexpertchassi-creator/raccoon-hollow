# ITEMS-SOUP-BATCH-09-P01

## 목적

국밥집의 장국·수제비·냉국·곰탕·삼계탕을 같은 사발 계열 안에서 국물색과 대표 건더기로 구분한다.

## 생성 대상

1. `kuk.png` — 맑은 간장빛 장국, 얇은 쇠고기와 표고 조각.
2. `sujebi.png` — 큼직하고 불규칙한 손수제비 반죽과 애호박.
3. `naeng.png` — 김 없이 차가운 청회색 국물, 오이·무채·얼음.
4. `gomtang.png` — 뽀얀 사골 국물, 넓은 쇠고기 편육과 파.
5. `samgye.png` — 작은 통닭, 산삼 한 뿌리, 대추가 보이는 삼계탕.

## 공통 기준

- 한 그릇을 실제 투명 배경에 생성하고 `128×224` 캔버스 중앙에 둔다.
- 사발의 기본 흙빛은 공유하되 국물과 대표 건더기의 큰 색면을 다르게 한다.
- 짙은 charcoal 외곽선, 절제된 명암, 미세한 한지 질감, 짧은 접지 그림자를 사용한다.
- 뜨거운 음식의 김은 짧고 단순하게, 냉국에는 김을 넣지 않는다.
- 수저·젓가락·쟁반·반찬·문자·UI·테두리·워터마크를 넣지 않는다.

## Hypothesis

- 같은 원형 사발이라도 버섯·반죽·채소채·편육·통닭의 중앙 실루엣으로 품목을 구분할 수 있다.
- 냉국은 청회색 그릇과 오이채, 무김 표식만으로 뜨거운 국물군에서 분리된다.
- 음식별 김 애니메이션 프레임은 만들지 않고 정지 PNG와 필요시 공용 코드 효과로 제한한다.
