# ITEMS-BUTCHER-STALL-BATCH-16-P01

## 목적

우거지·곱창·안심·한우 등심으로 물건 80종을 모두 채우고, 별도 물건 PNG가 올라가는 첫 대장간 좌판으로 좌판 공통 구조를 시험한다.

## 생성 대상

1. `ugeoji.png` — 둥근 광주리에 담아 볏짚끈으로 묶은 짙은 올리브색 우거지 잎 다섯 장.
2. `gopchang.png` — 짙은 나무판 위에 세 겹으로 정돈한 밝은 미색 곱창 고리와 깨끗한 절단면 하나.
3. `ansim.png` — 좁고 긴 나무판 위에 볏짚끈으로 한 번 묶은 길쭉하고 끝이 가는 진홍색 안심 필렛.
4. `hanwoo.png` — 검갈색 나무판 위의 두꺼운 타원형 한우 등심 한 장, 굵고 자연스러운 미색 마블링과 한쪽 지방 덮개.
5. `smith.png` — 낮은 U자형 목재·무쇠 좌대, 왼쪽의 작은 모루와 오른쪽의 짧은 쇠받침, 비어 있는 중앙 윗부분.

## 공통 기준

- 물건은 실제 투명 배경의 `128×224`, 좌판은 `192×176` 캔버스로 정리한다.
- 짙은 charcoal 외곽선, 따뜻한 흙빛 색면, 절제된 명암, 미세한 한지 질감을 사용한다.
- 식재료는 피·도축·사체·칼 없이 정돈된 판매 단위로 표현한다.
- 대장간 좌판은 건물이나 지붕이 아니라 한 격자 칸을 채우는 낮은 독립 받침이다.
- 좌판 중앙 윗부분에는 물건을 그려 넣지 않고 별도 `items/<id>.png`가 겹쳐질 공간을 남긴다.
- 인물·표지판·글자·UI·이름패·불꽃·연기·현대 포장·테두리·워터마크를 넣지 않는다.

## Hypothesis

- 남은 고기 품목은 잎 묶음·미색 고리·길쭉한 필렛·굵은 마블링 타원으로 서로 구분된다.
- 모든 좌판이 `낮은 공통 받침 + 양옆 업종 표식 + 빈 중앙` 구조를 공유하면 물건 오버레이와 업종 식별을 함께 만족시킬 수 있다.
- 대장간 좌판의 작은 모루와 무쇠판은 불꽃·망치 없이도 업종을 충분히 전달한다.
