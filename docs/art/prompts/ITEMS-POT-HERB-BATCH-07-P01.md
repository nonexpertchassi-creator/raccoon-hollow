# ITEMS-POT-HERB-BATCH-07-P01

## 목적

무장식 달항아리로 옹기점 8종을 마무리하고, 약재상의 첫 네 품목을 식물·동물성·광물성 재료 실루엣으로 구분한다.

## 생성 대상

1. `moonjr.png` — 이음선과 작은 굽만 남긴 넓고 둥근 미색 달항아리.
2. `root.png` — 볏짚으로 묶은 도라지 뿌리와 창 모양 잎, 작은 보랏빛 종꽃.
3. `ginseng.png` — 잔뿌리 많은 산삼 뿌리, 오엽과 작은 붉은 열매.
4. `antler.png` — 절단면이 보이는 짧은 녹용 한 쌍을 미색 끈으로 묶은 묶음.
5. `bezoar.png` — 펼친 한지 약포와 얕은 목제 약접시 위의 황토빛 천연 우황 한 덩이.

## 공통 기준

- 한 판매 단위를 실제 투명 배경에 생성하고 `128×224` 캔버스 중앙에 둔다.
- 짙은 charcoal 외곽선, 따뜻한 흙빛 색면, 절제된 명암, 미세한 한지 질감을 사용한다.
- 도라지와 산삼은 뿌리 모양뿐 아니라 잎·꽃·열매의 작은 식별 표식으로 구분한다.
- 녹용은 사슴 머리나 두개골 없이 절단 약재만, 우황은 알약·사탕·보석이 아닌 불규칙한 천연 덩이로 표현한다.
- 문자·라벨·금박·마법 광원·배경·UI·테두리를 넣지 않는다.

## Hypothesis

- 달항아리의 넓은 둥근 몸과 이음선은 술병의 긴 목과 다른 가격·품목 실루엣을 만든다.
- 도라지는 작은 종꽃, 산삼은 오엽과 붉은 열매를 남기면 뿌리 약재끼리도 축소 화면에서 구분된다.
- 녹용의 절단면은 일반 뿔 장식과 약재를 구분하는 최소 표식이다.
- 우황은 낯선 재료이므로 약포와 작은 접시를 하나의 판매 단위로 묶어 약재 문맥을 보강한다.
