# ITEMS-PAPER-POT-BATCH-05-P01

## 목적

지물포 8종을 지우산·지등·병풍으로 마무리하고, 옹기점의 재료 기준을 옹기·사발 두 종으로 시작한다.

## 생성 대상

1. `umbrel.png` — 접은 미색 한지 우산, 대나무 살, 굽은 나무 손잡이, 소박한 묶음끈.
2. `lantrn.png` — 미색 한지를 대나무 골조에 씌운 작은 지등, 안쪽의 약한 황색 빛.
3. `screen.png` — 네 폭 목재 틀과 절제된 산·갈대 수묵이 이어지는 작은 병풍.
4. `jar.png` — 갈색 유약, 둥근 몸, 뚜껑, 작은 귀가 보이는 생활 옹기.
5. `bowl.png` — 밝은 회미색 분청빛, 굽, 비정형 붓자국이 있는 빈 사발.

## 공통 기준

- 한 물건만 실제 투명 배경에 생성하고 `128×224` 캔버스 중앙에 둔다.
- 지물포는 한지빛·대나무·목재를, 옹기점은 흙·유약·물레 자국을 큰 재료 덩어리로 보여준다.
- 짙은 charcoal 외곽선, 절제된 명암, 미세한 손그림 재료감을 사용한다.
- 문자·붉은 등롱·긴 술·금박·궁전 장식·일본 문양·바닥·그림자·UI·테두리를 넣지 않는다.

## Hypothesis

- 지등은 붉은색과 장식을 제거하고 미색 한지 골조만 남기면 특정 중국식 등롱으로 치우치지 않는다.
- 지우산은 접은 자세와 소박한 굽은 손잡이를 쓰면 일본식 장식 우산보다 생활 도구로 읽힌다.
- 병풍은 네 폭과 낮은 산수만 남겨 작은 게임 물건으로 줄이고, 그림 속 글씨와 도장은 생략한다.
- 옹기점은 갈색 저장용 옹기와 밝은 식사용 사발의 재료·용도 차이로 첫 범위를 만든다.
