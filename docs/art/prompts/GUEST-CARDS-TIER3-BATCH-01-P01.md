# GUEST-CARDS-TIER3-BATCH-01-P01

## Discussion

3단은 2단의 수선된 마을을 다시 화려하게 꾸미는 단계가 아니다. 동물에게 옷이나 직업을 주면 손님 카드가 점장 캐릭터처럼 바뀌고, 인파를 넣으면 작은 카드에서 주인공이 묻힌다.

## Hypothesis

`11~15성 / 3단`은 `익숙한 단골 → 장날의 오래된 벗`으로 본다. 같은 개체·자세·계절·생활 장소를 유지하고, 열린 문·낮은 좌판·빛바랜 삼베 그늘막·준비된 광주리와 묶음처럼 사람 없이도 장날이 느껴지는 상업 흔적만 배경 가장자리에 늘린다.

## 대상과 장면

- `rabbit-3`: 봄 돌담길, 열린 대문, 봄나물 좌판·광주리·말아 둔 멍석.
- `magpie-3`: 감나무 돌담, 열린 한지문, 감과 포장 물품 좌판·광주리.
- `squirrel-3`: 가을 뒤뜰, 열린 창고, 도토리·밤 채반과 빈 광주리·곡식자루.
- `badger-3`: 늦가을 황혼 골목, 열린 창고, 덮은 광주리·곡식자루·세워 둔 손수레.
- `fox-3`: 노을 진 대문, 약초·포장 물품 좌판·옹기·말아 둔 멍석.

## 공통 금지

- 의상·장신구·직업 자세·도구를 든 손님·추가 동물·인파·문자·간판·프레임·별·등급색·마법·광효과 없음.
- 궁전·붉은 기둥·중국식 등롱·일본식 신사·금장·장식용 깃발 없음.
- 시장 물건은 동물보다 작고 배경 가장자리에 둔다.
