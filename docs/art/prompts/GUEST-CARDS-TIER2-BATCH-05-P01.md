# GUEST-CARDS-TIER2-BATCH-05-P01

## 목적

살쾡이·산양·담비·원앙·늑대의 1단 개체·자세·계절을 유지하면서 길과 생활 공간의 수선만 한 단계 올린 2단 카드 묶음.

## 기준과 장면

- 같은 개체·무늬·자연 자세·계절·한지 수채 질감 유지.
- `512×768`, 약 7% 안전 여백, 의상·장신구·마법 효과·프레임·별·글자·등급색 없음.
- `wildcat-2`: 초승달 황혼, 손본 돌담·대문과 따뜻한 한지 창 한 곳.
- `goral-2`: 같은 바위 비탈, 수선된 돌계단·목재 난간과 아래쪽 마을 풍경.
- `marten-2`: 단풍 숲길, 손본 돌담·나무 대문, 묶은 장작·낙엽 더미·열매 광주리.
- `mandarin-2`: 채도를 누른 가을 연못, 수선된 연못 돌축대·디딤돌·작은 정자와 정돈한 갈대.
- `wolf-2`: 푸른 겨울 저녁, 수선된 돌길·담장, 장작과 한두 채의 은은한 한지 창.

## 출력

- 마스터: `docs/art/generated/cards/CARD-<ID>-T2-V0.1-master.png`
- 런타임: `godot/art/cards/<id>-2.png`
- QA: `docs/art/qa/guest-cards-tier2-batch-05.png`
- 사용자 승인 전까지 모두 `Generated / 초안`이다.

## 판정

- 다섯 종 모두 1단의 개체와 자세가 읽히며, 새 장식이나 신분 표식 없이 생활 공간의 회복만 보인다.
- 원앙은 개체 채도가 높아 배경 채도를 낮게 유지했고, 늑대는 눈·마을 불빛을 발광 연출로 키우지 않았다.
- 다섯 런타임 파일은 정확한 `512×768`이다.
- 실제 카드 프레임과 사용자 승인이 남아 있어 `초안`을 유지한다.
