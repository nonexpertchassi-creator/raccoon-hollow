# GUEST-CARDS-TIER1-BATCH-01-P01

## 목적

손님 카드 1단의 첫 5장으로, 필드용 작은 스프라이트와 다른 ‘오래 보는 큰 그림’의 밀도와 공통 구도를 정한다.

## 공통 생성 기준

- 2:3 세로, 게임용 런타임 512×768
- 동물을 정면 또는 약한 3/4 정면으로 크게 배치하고 몸 전체가 읽히게 함
- 가장자리 7%에는 중요한 얼굴·귀·꼬리를 두지 않음
- 조선 후기 서민 마을의 흙길·돌담·초가·생활 재료를 넓은 색면으로 사용
- 따뜻한 손그림 색면, 짙은 갈색 외곽선, 절제된 셀 명암, 미세한 한지 질감
- 1단은 자연 동물 상태. 옷·모자·장신구·인간 자세·마법 효과 없음
- 카드 테두리·등급색·별·글자·UI는 코드가 그리므로 이미지에 넣지 않음
