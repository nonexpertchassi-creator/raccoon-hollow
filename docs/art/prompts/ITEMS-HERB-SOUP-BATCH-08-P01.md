# ITEMS-HERB-SOUP-BATCH-08-P01

## 목적

약재상 8종을 마무리하고 국밥집의 첫 품목을 시작하면서 마른 뿌리·버섯·향목·약고·국물 음식의 재료 실루엣을 넓힌다.

## 생성 대상

1. `danggui.png` — 밝은 절단면 세 개를 곁들인 마른 당귀 뿌리 묶음.
2. `reishi.png` — 짙은 적갈색 동심 무늬와 황토빛 테두리의 영지 두 송이.
3. `agar.png` — 검은 수지결이 보이는 불규칙한 침향 조각과 짧은 쪼갠 향목 묶음.
4. `elixir.png` — 뚜껑을 살짝 연 갈색 약단지와 검은 경옥고, 작은 목제 약숟가락.
5. `bap.png` — 밥알·맑은 장국·파·쇠고기와 짧은 김 두 줄이 보이는 미색 국밥 사발.

## 공통 기준

- 한 판매 단위를 실제 투명 배경에 생성하고 `128×224` 캔버스 중앙에 둔다.
- 짙은 charcoal 외곽선, 따뜻한 흙빛 색면, 절제된 명암, 미세한 한지 질감을 사용한다.
- 당귀는 잎 없는 마른 뿌리와 절편, 영지는 갓의 동심 무늬, 침향은 검은 수지결로 식별한다.
- 경옥고는 글자·봉인·금장식 없이 열린 약단지와 검은 약고만 사용한다.
- 국밥은 한 그릇만 두고 수저·반찬·쟁반을 붙이지 않는다. 김은 짧은 정지 표식이며 별도 애니메이션 프레임으로 늘리지 않는다.
- 배경·UI·테두리·워터마크·문자를 넣지 않는다.

## Hypothesis

- 약재상 후반 네 종은 색보다 절편·층진 갓·검은 수지결·열린 단지라는 구조 차이로 구분된다.
- 국밥의 흰 밥알과 맑은 국물은 이후 장국·곰탕·삼계탕과 구분할 기본 식별점이 된다.
- 김의 움직임이 필요해져도 음식별 추가 프레임보다 공용 코드 효과가 제작량을 억제한다.
