# GUEST-CARDS-TIER1-BATCH-02-P01

## 목적

귀함부터 영물까지 등급이 올라갈 때, 장식과 광효과가 아니라 계절·공간·동물의 실루엣으로 품격 차이를 만드는 카드 5장을 시험한다.

## 공통 기준

- `GUEST-CARDS-TIER1-BATCH-01-P01`의 2:3 구도, 한지 질감, 가장자리 안전 여백 유지
- 1단 자연 동물, 정면 또는 약한 3/4 정면, 몸 전체가 읽히는 큰 배치
- 프레임·등급색·별·글자·UI 없음
- 한국 서민 마을의 돌담·흙길·초가·기와·옹기·논둑을 배경 재료로 사용
