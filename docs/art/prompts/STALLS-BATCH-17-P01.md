# STALLS-BATCH-17-P01

## 목적

첫 대장간 좌판의 폭·높이·바닥 접점·빈 중앙을 공통 골격으로 삼아 필방·지물포·옹기점·약재상·국밥집 좌판을 서로 다른 재료와 고정 설비로 구분한다.

## 생성 대상

1. `brush.png` — 한지 작업면을 둔 낮은 서안, 왼쪽 고정 벼루와 오른쪽 빈 붓받침.
2. `paper.png` — 밝은 목재 좌대, 왼쪽 종이 두루마리와 오른쪽 접은 무지 종이의 짧은 옆선반.
3. `pot.png` — 황토 작업판과 낮은 벽돌 기단, 왼쪽 고정 물레판과 오른쪽 둥근 가마 받침.
4. `herb.png` — 양쪽에만 작은 무표기 약장, 아래쪽 얕은 건조 살대가 있는 목재 좌대.
5. `soup.png` — 검은 온장판과 놋쇠 고리, 왼쪽 장작 둘과 오른쪽 뚜껑 단지, 전면의 아주 작은 잉걸 틈.

## 공통 기준

- 모든 좌판은 실제 투명 배경의 `192×176`, 하단 접점 정렬로 정리한다.
- 대장간 좌판의 넓고 낮은 U자 골격과 동일한 카메라·폭·높이를 유지한다.
- 중앙 윗부분은 별도 `items/<id>.png`가 올라가도록 비우고 업종 표식은 양옆 또는 낮은 하단에만 둔다.
- 짙은 charcoal 외곽선, 따뜻한 흙빛 색면, 절제된 명암, 미세한 한지 질감을 사용한다.
- 건물·지붕·벽·인물·표지판·글자·UI·이름패·테두리·워터마크를 넣지 않는다.

## Hypothesis

- `낮은 공통 받침 + 양옆 업종 표식 + 빈 중앙`은 열 가게 좌판 전체에 재사용할 수 있다.
- 좌판 자체의 색보다 고정 작업면·옆선반·흙 기단·서랍·온장판 같은 구조가 업종을 더 잘 구분한다.
- 별도 물건이 겹쳐져도 양옆 표식은 가려지지 않고 좌판의 업종을 보조한다.
