# GUEST-CARDS-TIER3-BATCH-05-P01

## 목적

살쾡이·산양·담비·원앙·늑대의 2단 개체·자세·계절·생활 장소를 유지하며, 황혼길·산길·단풍마당·연못가·겨울길에 절제된 3단 장날 흔적을 시험한다.

## Hypothesis 적용

- `11~15성 / 3단 = 익숙한 단골 → 장날의 오래된 벗`.
- 같은 동물과 자연 자세를 유지하고 장터 물건은 동물의 측면과 배경에만 둔다.
- 황혼·겨울의 따뜻함은 건물에 붙은 한지 창호로만 내고 이동식 등롱은 쓰지 않는다.
- 동물 고유색이 강한 원앙은 새 장터 물건을 미색·갈색·쑥빛으로 낮춘다.

## 대상과 장면

- `wildcat-3`: 가을 황혼 마을길, 삼베 그늘막 아래 접은 천·포장 꾸러미·광주리.
- `goral-3`: 산중 돌길 산물장, 잣·약초·포장 식량·장작·물장독.
- `marten-3`: 단풍 마을길 숲 산물장, 밤·도토리·버섯·묶은 장작.
- `mandarin-3`: 가을 연못 산물장, 연근·미나리·갈대·말아 둔 멍석.
- `wolf-3`: 푸른 겨울길 저장품장, 장작·덮은 광주리·마른 뿌리·포장 식량.
