# ITEMS-SMITH-BRUSH-BATCH-02-P01

## 목적

대장간 8종을 마무리하고 필방의 첫 문방구 3종을 같은 `128×224` 물건 계약에 연결한다.

## 생성 대상

1. `lock.png` — 옆으로 긴 단순한 옛 철 자물쇠. 낮은 걸쇠, 작은 열쇠구멍, 금장 최소화.
2. `cauldr.png` — 뚜껑·작은 귀·세 발이 보이는 검은 무쇠 가마솥.
3. `brush.png` — 대나무 자루, 짙은 물미, 뾰족한 붓털의 세로 붓.
4. `ink.png` — 금박·문자 없이 작은 구름 양각만 있는 검은 먹.
5. `inkstone.png` — 먹물 웅덩이와 갈이 면이 나뉜 낮은 검은 벼루.

## 공통 기준

- 물건 하나, 실제 투명 배경, `128×224`, 화면 표시 `64×112`.
- 짙은 charcoal 외곽선, 큰 재료 색면, 절제된 부드러운 명암, 미세한 손그림 질감.
- 물건의 실제 비율은 유지하되 투명 캔버스 안에서 가로·세로 중앙에 둔다.
- 사람·동물·손·받침대·바닥·그림자·글자·가격표·등급 효과·UI·테두리를 넣지 않는다.
- 문방구는 중국 궁중품처럼 보이는 금박·붉은 칠·용무늬·긴 술 장식을 피한다.

## Revision 기록

- 자물쇠 V0.1은 높은 U자 고리와 넓은 금장 띠 때문에 현대 판타지 보물상자 자물쇠처럼 읽혀 사용하지 않는다.
- V0.2는 옆으로 긴 철 몸체와 낮은 사각 걸쇠로 다시 생성하고 금색은 작은 핀과 열쇠구멍에만 제한했다.

## Hypothesis

- 가로로 넓은 가마솥·벼루·자물쇠도 캔버스 중앙에 두면 세로 도구와 같은 카드 슬롯에서 처져 보이지 않는다.
- 문방구는 금박이 아니라 대나무·먹색·돌의 재료 차이로 가치와 종류를 구분한다.
- 실제 점장 손 오버레이에서는 원본 캔버스를 그대로 쓰지 않고 보이는 물체의 경계 기준으로 축소한다.
