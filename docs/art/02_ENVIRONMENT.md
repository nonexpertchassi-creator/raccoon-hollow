## 1. Discussion

환경은 배경 장식이 아니라 이 게임의 성장 상태를 보여주는 주된 시스템 표현이다. 같은 마을이 수선과 손님 증가를 통해 살아나야 하므로, 폐허와 복구 상태는 서로 다른 문화권이나 시대가 아니라 **하나의 건축 DNA가 다른 관리 상태를 보이는 것**이어야 한다.

한국성도 캐릭터 의상보다 환경에서 먼저 읽혀야 한다. 다만 궁궐과 양반가의 상징을 많이 넣는 방식이 아니라 서민 건축과 생활 도구의 조합으로 만든다.

## 2. Decision — World DNA

### 2.1 기본 공간

- 조선 후기 서민 마을에서 영감을 받은 소규모 생활권
- 완벽히 보존된 민속촌이 아니라 오래되고 수선 가능한 장소
- 넓은 광장보다 건물 사이의 흙길과 작은 생활 공간 중심
- 건물은 낮고 소박하며 사람 손이 닿는 크기로 표현
- 활기 회복은 청결, 수선, 상품, 손님, 작은 식생으로 보여줌

### 2.2 Architecture DNA

- 목재 기둥과 보가 읽히는 단순 한옥 구조
- 밝은 흙벽 또는 회벽
- 한지 격자 창호
- 초가 또는 절제된 기와지붕
- 낮은 흙·돌담
- 작은 툇마루나 문턱
- 비대칭 생활 흔적은 허용하되 전체 실루엣은 단순하게 유지

### 2.3 금지되는 건축 인상

- 궁전처럼 다층·대형인 지붕
- 과장되어 위로 치솟은 처마
- 붉은 기둥이 반복되는 회랑
- 금색 장식과 거대한 현판
- 중국식 등롱, 문루, 패방
- 일본식 도리이, 신사 지붕, 마치야형 상점 전면
- 서양 중세 판타지 목조 건물
- 아이소메트릭 타일 블록처럼 독립된 다이아몬드 지면

## 3. Decision — Recovery / Revival 표현

### 폐허 상태

- 방치되었지만 복구 가능해야 함
- 빛바랜 벽, 일부 처진 초가, 빠진 기와 몇 장
- 삐걱하거나 기울어진 문짝, 닫힌 창호
- 마른 풀, 먼지, 비어 있는 광주리
- 목재 구조의 작은 수선 필요 지점
- 전소, 완전 붕괴, 전쟁 피해처럼 보이는 잔해는 피함

### 복구 상태

- 구조가 반듯하고 지붕이 수선됨
- 창호가 밝고 깨끗함
- 문이 열려 있거나 출입이 가능해 보임
- 정돈된 장독과 광주리, 작은 상품 흔적
- 짧은 동선 위에 손님이 있음
- 제한된 녹색 식생과 따뜻한 색 포인트
- 새 궁전처럼 번쩍이거나 과도하게 부유해 보이지 않음

### 공통점

- 같은 목재, 흙벽, 창호, 지붕 구조
- 같은 카메라와 투영
- 같은 외곽선과 채색 방식
- 비슷한 건물 면적과 높이

## 4. Decision — Korean Props

| 소품 | 기능 | 단순화 원칙 |
|---|---|---|
| 장독/옹기 | 저장과 생활감 | 2~3개를 크기 차이로 묶고 문양은 생략 |
| 지게 | 운반과 노동 | A자 실루엣과 등받이만 명확하게 |
| 광주리 | 상품과 농촌 생활 | 짜임은 선 몇 개로만 암시 |
| 멍석 | 작업/진열 바닥 | 직사각 큰 면과 얕은 결만 사용 |
| 붓 | 향후 상품 단서 | V0.1에서는 다발 또는 통에 꽂힌 큰 실루엣만 허용 |
| 한지 | 상품/창호 | 종이 더미는 큰 밝은 면으로 단순화 |
| 낮은 담장 | 공간 구획 | 동선을 막지 않는 낮이와 짧은 길이 |

소품은 문화적 증거이면서 게임 동선을 설명해야 한다. 문화재 도감처럼 전부 한 화면에 나열하지 않는다.

## 5. Hypothesis — V0.1 공간 구성

| ID | 시험값 | 승인 기준 |
|---|---|---|
| EN-H01 | 폐허와 복구 상점은 같은 축척으로 두되 정확한 위치 관계는 여러 세로 구도에서 탐색한다. | 좁은 세로 화면에서도 전후 비교가 자연스럽고 패널처럼 갈라지지 않는가? |
| EN-H02 | 길은 두 건물과 손님 동선을 연결하되 정확한 시작점과 방향은 고정하지 않는다. | 세로형 손님 동선과 화면 깊이가 소실점 없이 읽히는가? |
| EN-H03 | 건물 사이 간격은 건물 폭의 약 35~50%로 둔다. | 답답하지 않으면서 작은 마을로 묶이는가? |
| EN-H04 | 소품은 장독 2~3개 묶음, 지게 1개, 광주리 1~2개, 멍석 1개 이하로 제한한다. | 한국성이 읽히고 입구와 길이 막히지 않는가? |
| EN-H05 | 폐허 쪽은 마른 풀, 복구 상점 쪽은 저채도 녹색 식생을 소량 배치한다. | 텍스트 없이 Recovery가 보이는가? |
| EN-H06 | 복구 상점은 초가를 기본으로 하고 기와는 마을 배경의 보조 요소로 제한한다. | 소박함을 유지하면서 한국 건축으로 읽히는가? |
| EN-H07 | 배경 건물은 추가하지 않거나 실루엣 수준으로만 둔다. | 핵심 두 건물의 비교와 플레이 스케일을 방해하지 않는가? |

## 6. 지면과 그림자

### Decision

- 주 지면은 먼지 낀 베이지와 황토색의 흙길
- 잔디가 지면을 카펫처럼 덮지 않음
- 길 가장자리는 유기적이지만 복잡한 노이즈를 만들지 않음
- 접지 그림자는 짧고 단순하며 한 방향으로 통일
- 건물의 긴 투영 그림자나 극적인 시간대 조명은 사용하지 않음

### Hypothesis

- 지면 표면의 한지 grain은 전체 색면을 깨지 않을 정도의 3~5% 시각 강도로 시작한다.
- 돌은 길 가장자리에 3~6개 정도의 큰 형태만 사용한다.
