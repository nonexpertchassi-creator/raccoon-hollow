# 03. Buildings

## 상태: `Queued / Specialized shops locked`

Art Concept Blueprint V0.1은 승인되었다. 현재는 다음 순서인 캐릭터 시트를 먼저 제작하며, 개별 전문 상점 디자인은 계속 잠근다.

현재 잠금 대상:

- 대장간
- 붓가게
- 종이가게
- 도자기가게
- 약재상

이 문서에는 아직 개별 건물의 형태, 색, 간판, 상품 진열, 레벨업 외형을 `Decision`으로 기록하지 않는다.

## 기본 건물 시트 시작 조건

다음 항목은 Blueprint V0.1에서 승인되었다.

- 카메라와 투영
- 건물 : 캐릭터 : 소품 비율
- Architecture DNA
- 한국 너구리 점주 플레이 스케일
- 폐허/복구 상태 대비
- 팔레트와 렌더링 스타일

기본 건물 시트는 한국 너구리 캐릭터 시트 승인 후 시작한다. 대장간·붓가게·종이가게·도자기가게·약재상은 기본 건물 시트가 통과할 때까지 계속 `Locked`다.

## 승인 후 기록 순서

1. 모든 상점에 공통인 기본 건물 원형
2. 폐허 → 수선 중 → 영업 중의 상태 변화
3. 상점 1종의 상품과 작업 기능
4. 축소 화면 검수
5. 통과한 규칙만 다른 상점으로 확장
