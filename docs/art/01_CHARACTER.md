# 01. Character — Raccoon Dog Shopkeeper

## 문서 상태

- 버전: `V0.1-draft`
- 현재 대상: 기본 너구리 점주 1종
- 상태: 핵심 DNA는 `Decision`, 정확한 비율과 손님 종은 `Hypothesis`
- 선행 게이트: Art Concept Blueprint V0.1

## 1. Discussion

이 캐릭터의 성공 기준은 큰 원화에서 얼굴이 예쁜지가 아니다. 실제 모바일 타이쿤 화면에서 작게 보일 때도 다음 세 가지가 동시에 읽혀야 한다.

1. 라쿤이 아닌 한국 너구리다.
2. 복구된 상점 앞에서 일하는 점주다.
3. 귀엽지만 유아용 마스코트처럼 보이지 않는다.

따라서 얼굴 무늬나 복식보다 몸 실루엣, 꼬리, 귀, 작업 자세가 중요하다.

## 2. Decision — Character DNA

### 종과 실루엣

- 종: 한국 너구리 / raccoon dog
- 작은 둥근 귀
- 짧은 주둥이지만 완전히 납작한 아기 얼굴은 피함
- 짧은 다리
- 통통하고 낮은 무게중심
- 한 덩어리로 읽히는 복슬한 꼬리
- 꼬리에 선명한 고리무늬 없음
- 팔과 다리는 몸에서 구분되되 가늘고 길게 만들지 않음

### 얼굴과 털

- 기본 털색: 따뜻한 회갈색과 갈색
- 눈 주변의 어두운 털은 부드럽고 가장자리가 약함
- 라쿤식 좌우 연결 검은 마스크 금지
- 눈은 작은 점 또는 단순 타원으로 유지
- 흰 눈동자와 반짝임을 과장하지 않음
- 표정은 성실하고 다정하되 과도한 활짝 웃음은 피함

### 플레이 스케일 원칙

- 큰 일러스트를 축소하지 않고 작은 화면 실루엣부터 설계
- 얼굴보다 귀, 몸통, 다리, 꼬리, 작업 포즈의 덩어리 구분을 우선
- 손가락, 옷깃 봉제선, 털 한 올 등 축소 시 사라지는 디테일은 넣지 않음
- 접지 그림자는 발밑의 짧은 타원형으로 제한
- 손님보다 약간 더 눈에 띄되 건물보다 먼저 화면 전체를 지배하지 않음

## 3. Hypothesis — Blueprint에서 시험할 값

| ID | 시험값 | 승인 기준 |
|---|---|---|
| CH-H01 | 머리:몸통을 약 1:1로 시작하되 전체 키는 2.3~2.6 heads 수준으로 보이게 한다. | 아기처럼 보이지 않으면서 귀여운가? |
| CH-H02 | 꼬리는 몸통 폭의 약 60~75%, 전체 키의 약 40~50% 길이로 단순화한다. | 작게 봐도 너구리 꼬리로 읽히고 라쿤처럼 보이지 않는가? |
| CH-H03 | 눈 주변 음영은 얼굴 전체 명암보다 한 단계만 어둡게 한다. | 종 특징이 남으면서 검은 마스크를 피하는가? |
| CH-H04 | 점주는 상점 파사드 폭의 약 9~12% 크기로 배치한다. | 모바일 게임 캐릭터로 읽히는가? |
| CH-H05 | 손님은 점주 키의 90~105%, 채도와 의상 정보는 점주보다 낮게 한다. | 군중이 되면서도 주인공 위계가 유지되는가? |
| CH-H06 | 첫 손님 후보는 토끼, 들쥐, 작은 토종개 계열을 사용한다. | 서로 구분되지만 별도 캐릭터 시트가 필요할 만큼 복잡하지 않은가? |
| CH-H07 | 점주는 복식을 생략하고 자연 털 실루엣만 사용한다. 비교안은 짧은 베이지 저고리·흙갈색 바지·작은 앞치마를 사용한다. | 34×34에서 역할이 더 잘 읽히고 손님과도 구분되는가? |
| CH-H08 | 전신 옷은 생략하고 허리 아래의 짧은 황토갈색 작업 앞치마만 사용한다. | 털 실루엣을 해치지 않으면서 점주 역할이 더 빨리 읽히는가? |

## 4. 형태 우선순위

작게 보일 때 다음 순서로 형태가 살아 있어야 한다.

1. 둥근 귀 두 개와 낮은 머리 형태
2. 짧고 통통한 몸통
3. 짧은 다리와 안정된 접지
4. 무늬 없는 복슬한 꼬리
5. 제작/판매 동작이 만드는 팔의 방향
6. 약한 눈 주변 털

## 5. 기본 포즈 범위

Blueprint V0.1에서는 포즈 세트를 확장하지 않는다.

- 점주: 상점 앞에 서서 손님을 맞거나 작은 물건을 정리하는 중립 작업 포즈 1개
- 손님: 걷기, 대기, 상품 보기 중 단순 포즈
- 과장된 점프, 큰 손짓, 전투 자세, 초상화 포즈는 사용하지 않음

## 6. Character Hard Fail

- raccoon 또는 red panda로 읽힘
- 꼬리에 선명한 고리무늬가 있음
- 날카로운 검은 눈 마스크가 있음
- 귀가 크고 뾰족함
- 다리가 길고 몸이 날씬함
- 머리가 과도하게 크거나 눈이 유아용 캐릭터처럼 큼
- 화려한 한복, 왕실 복식, 사극 소품이 캐릭터를 지배함
- 플레이 화면에서 얼굴만 읽히고 작업 역할과 꼬리 실루엣은 사라짐

## 7. Blueprint 승인 후 확장 순서

1. 정면/측면/후면 게임 스케일 턴어라운드
2. 기본 작업 포즈 3종
3. 걷기와 물건 운반 실루엣
4. 표정 최소 세트
5. 손님 종별 단순화 규칙

현재는 위 항목을 제작하지 않는다.
