# 동물 캐릭터 신체·의상 배치 규격 V0.1

> 상태: **초기 기준값(Hypothesis)**
> 목적: 동물마다 종의 특징은 달라도, 같은 게임 안에서 크기·무게중심·팔다리 단순화 정도가 흔들리지 않게 한다.

## 1. 공통 캔버스

| 항목 | 기준 |
|---|---:|
| 제작 파일 | 144 × 144 px, RGBA |
| 게임 표시 | 72 × 72 px |
| 가로 중심 | x = 72 |
| 접지선 | y = 143 |
| 기본 안전 여백 | 위 6~10 px, 좌우 10~18 px |

- 발끝의 가장 낮은 불투명 픽셀은 `y=143`에 닿게 한다.
- 몸은 캔버스 중심에 놓되 꼬리 때문에 몸통 자체가 밀려나지 않게 한다.
- 귀·발·꼬리·얼굴 외곽선은 의상 때문에 잘리거나 이동하지 않는다.
- 좌우 반전으로 사용하는 방향은 몸통 중심과 발 접지점이 동일해야 한다.
- 현재 런타임 원화는 `↘ side`와 `↗ back` 두 장만 필수로 만든다. 반대 방향은 코드 반전을 사용하고, 네 방향 비교 시트는 필요한 경우에만 만든다.

## 2. A타입 너구리 기준 상자

현재 런타임 파일을 기준으로 측정한 값이다.

| 방향 | 보이는 영역 | 시작점(약) | 목표 범위 |
|---|---:|---:|---:|
| 가까운 3/4 (`side`) | 111 × 136 px | x=16, y=8 | 폭 108~112 / 높이 132~136 |
| 먼 3/4 (`back`) | 96 × 130 px | x=24, y=14 | 폭 94~100 / 높이 128~132 |

### 비율

- 귀 포함 전체 캐릭터 높이를 `100`으로 본다.
- 귀 높이: `16~20`
- 머리·얼굴 덩어리: `46~50`
- 배·몸통·눌린 발 덩어리: `50~54`
- 발 높이: `6~9`, 각 발 폭: 전체 높이의 `14~18`
- 팔이 외곽선 밖으로 드러나는 길이: `16~22` 이내
- 팔꿈치·무릎 관절은 그리지 않는다.
- 꼬리 지름: 전체 높이의 `30~38`; 몸통보다 앞으로 나오지 않는다.

머리와 몸통 사이에 목선이나 완전한 분할선을 만들지 않는다. 얼굴, 몸통, 다리는 하나의 부드러운 덩어리로 읽혀야 한다.

## 3. 의상 배치선

| 요소 | 144px 기준 | 비율 기준 |
|---|---:|---:|
| 허리선 | y=86~92 | 전체 높이의 58~62% |
| 앞치마 아래 끝 | y=126~131 | 발 윗부분에서 종료 |
| 어깨끈 시작점 | y=58~68 | 얼굴 아래·팔 위 |
| 발 보호 구역 | y=132~143 | 의상 침범 금지 |

- 앞치마는 허리선 아래에 얹는다. 배 무늬의 크기를 늘리거나 몸 형태를 바꾸지 않는다.
- 멜빵은 어깨끈 경로만 추가한다. 귀·얼굴·팔 위치는 그대로 둔다.
- 뒷매듭은 꼬리 뿌리와 겹치지 않게 좌우로 비켜 둔다.
- 손에 드는 도구 기준점은 만들지 않는다. 도구 없는 완성형 캐릭터를 기본으로 한다.
- 최종 이미지는 일체형이어도 제작할 때는 `신체 원본 위에 의상 종이를 얹는다`고 생각한다.

## 4. 털색과 무늬

털색과 무늬는 신체 구조와 분리해 관리한다.

- `신체 규격`: 키, 폭, 귀·발·팔·꼬리 위치
- `외형 규격`: 기본 털색, 눈가 무늬, 등 무늬, 꼬리 무늬
- `의상 규격`: 허리선, 앞치마 면, 멜빵 경로

무늬가 달라도 신체 외곽선과 발 위치는 바뀌지 않는다. 방향별 무늬는 같은 개체의 한 무늬가 몸을 돌아 이어진 것처럼 설계하며, 좌우 반전 때문에 귀나 몸의 고정 무늬가 다른 쪽으로 순간 이동하지 않게 한다. 방향 제작이 불안정한 비대칭 무늬는 귀·얼굴에서 제거하고 등판의 큰 단색 면처럼 단순화한다.

## 5. 다른 동물로 확장할 때

공통 기준은 `귀·뿔·긴 꼬리를 제외한 몸 중심(core body)`이다. 종 특징 때문에 전체 키만 키우지 말고 몸 중심을 먼저 맞춘다.

| 종 | 몸 중심 높이 | 종 특징 허용 범위 | 팔·앞다리 기준 |
|---|---:|---:|---:|
| 너구리 | 112~120 px | 귀 20~27 px, 꼬리 지름 41~52 px | 노출 22~30 px, 관절 없음 |
| 토끼 | 100~112 px | 귀 30~40 px, 전체 높이 132~140 px | 너구리와 같거나 10% 가늘게 |
| 까치 | 88~100 px | 머리 26~34 px, 꼬리는 뒤쪽 안전영역 사용 | 팔 대신 날개 34~44 px, 접힌 큰 색면 |
| 소형 포유류 | 104~116 px | 귀 14~28 px | 노출 18~27 px |
| 대형 포유류 | 116~126 px | 뿔·갈기는 위쪽 여백 사용 | 길이보다 폭을 키움 |

### 토끼

- 긴 귀는 몸을 늘리는 요소가 아니라 머리 위에 붙는 종 식별자다.
- 귀 때문에 얼굴과 몸이 작아 보이지 않도록 몸 중심은 너구리의 약 90~95%를 유지한다.
- 귀 사이 간격은 얼굴 폭의 18~26%, 한쪽 귀 폭은 얼굴 폭의 16~22%로 시작한다.

### 까치

- 날개는 손이 달린 팔처럼 그리지 않고 몸 옆에 붙은 하나의 접힌 색면으로 처리한다.
- 접힌 날개 길이는 몸 중심 높이의 35~45%를 넘지 않는다.
- 가는 다리를 길게 보여주지 않고 발과 함께 10~14 px 안에서 단순화한다.
- 긴 꼬리는 접지점과 몸 중심을 밀지 않도록 뒤쪽으로 뺀다.

## 6. 공통 실패 조건

- 종 특징을 넣느라 몸 중심 크기가 캐릭터마다 제멋대로 변함
- 옷을 입히면서 귀가 잘리거나 발 위치가 이동함
- 앞치마가 가슴까지 올라와 상체 의상처럼 보임
- 팔·다리에 관절이 생겨 사람처럼 접힐 것 같음
- 꼬리 때문에 몸통이 캔버스 중심에서 벗어남
- 무늬를 바꾸면서 배 무늬나 몸 외곽선까지 함께 확대됨
- 72×72에서 귀·몸·발보다 봉제선과 장식이 먼저 보임
