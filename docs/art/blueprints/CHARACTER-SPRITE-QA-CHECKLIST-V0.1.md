# 캐릭터 스프라이트 제작·검수 지침 V0.1

> 목적: 방향, 크기, 시점, 무늬, 톤이 서로 다른 그림을 한 묶음으로 확정하는 실수를 막는다.
> 적용 대상: 점장·일꾼·촌장 등 144×144 동물 캐릭터 전부.

## 1. 절대 하지 않을 행동

1. **한 장만 보고 통과시키지 않는다.** 같은 단계의 A~D를 한 줄에 놓고 비교하기 전에는 확정·라이브러리 등록·깃 반영을 하지 않는다.
2. **방향 이름만 프롬프트에 쓰지 않는다.** `↘`는 얼굴 끝이 화면 오른쪽, 꼬리가 화면 왼쪽이고 `↗`도 얼굴 끝이 화면 오른쪽, 꼬리가 화면 왼쪽이라는 시각 단서를 함께 적는다.
3. **이동 방향 때문에 걷는 자세를 만들지 않는다.** 기본 프레임은 언제나 차렷자세다. 두 발은 같은 크기, 같은 접지선, 배 바로 아래에 둔다.
4. **몸의 고정 무늬를 화면 좌우 기준으로 뒤집지 않는다.** 무늬는 동물 몸의 같은 자리에 붙어 있어야 한다. 여러 방향에서 유지하기 어려운 귀·얼굴 비대칭 무늬는 쓰지 않는다.
5. **타입별로 다시 그린 그림을 크기 확인 없이 섞지 않는다.** 털색·무늬만 다른 타입은 눈, 귀, 몸통, 발 위치가 기준판과 2px 넘게 달라지면 실패다.
6. **투명 배경·중앙·발끝만 맞았다고 통과시키지 않는다.** 방향, 차렷자세, 눈 크기, 시점, 꼬리 보존, 톤까지 확인해야 한다.
7. **가장 큰 한 덩어리만 남기는 방식으로 캐릭터를 자르지 않는다.** 몸에서 조금 떨어진 꼬리·손·장식이 사라질 수 있다. 모든 의도된 조각을 보존하거나 누락을 자동 검사한다.
8. **가장 큰 캐릭터 하나로 전체 배율을 결정하지 않는다.** 큰 타입 하나가 A~C를 함께 축소시킨다. 기준 몸통 상자와 방향별 목표 크기로 맞춘다.
9. **실제로 쓰지 않는 네 방향을 습관적으로 만들지 않는다.** 현재 필수 원화는 `↘ side`, `↗ back` 두 장이다. 반대쪽은 코드 반전을 사용한다.
10. **이전 원화와 최신 원화를 섞지 않는다.** 승인 원화 파일명을 하나의 목록에 먼저 고정한 뒤 파생 파일을 만든다.

## 2. 제작 전 고정값

- 캔버스: 144×144 RGBA
- 가로 중심: x=72
- 접지선: y=143
- 방향: `↘ side`, `↗ back`
- 자세: 차렷자세, 짧은 팔·발, 관절 없음
- 의상: 몸 위에 얹은 종이처럼 취급하며 귀·눈·배 무늬·발을 움직이지 않음
- 같은 종의 A~D 타입: 신체는 동일하고 털색·큰 무늬만 다름

### 방향별 외곽 목표

| 방향 | 폭 | 높이 |
|---|---:|---:|
| `side` | 108~112px | 132~136px |
| `back` | 94~100px | 128~132px |

외곽 상자는 꼬리를 포함한 1차 경고값이다. 최종 판단은 몸통·눈·귀·발을 A 기준판에 겹쳐서 한다.

## 3. 같은 종 A~D 겹침 검사

같은 단계·같은 방향끼리 반투명하게 겹쳐 다음 항목을 본다.

| 항목 | 허용 차이 |
|---|---:|
| 귀 끝 위치 | 2px 이내 |
| 눈 중심 위치 | 2px 이내 |
| 눈 검은 타원 폭·높이 | 2px 이내 |
| 몸통 양옆 | 3px 이내 |
| 허리선 | 2px 이내 |
| 두 발의 크기·간격 | 2px 이내 |
| 접지선 | 0px |

허용값을 넘으면 털색 타입 차이가 아니라 다른 신체·다른 카메라로 판정한다.

## 4. 톤앤매너 검사

- 눈은 A 기준판과 같은 작은 검은 타원과 작은 하이라이트를 쓴다. 흰자나 큰 동그란 눈을 새로 만들지 않는다.
- 귀는 둥근 삼각형, 몸에 붙은 짧은 형태를 유지한다. 길고 뾰족한 귀로 바꾸지 않는다.
- 외곽선은 진한 적갈색의 약간 끊긴 색연필 선이다. 매끈한 검정 벡터선으로 바꾸지 않는다.
- 명암은 최대 두 단계다. 재질 표현보다 작은 화면의 색면 구분을 우선한다.
- 털색이 밝아져도 채도·대비·하이라이트 양만 혼자 커지지 않게 한다.
- 배, 눈가, 등, 꼬리 무늬는 넓고 단순한 한 덩어리를 우선한다. 점박이·잔무늬로 타입을 구분하지 않는다.

## 5. 확정 전 행동 순서

1. 최신 원화 파일명과 사용 방향을 확인한다.
2. A~D 같은 단계 비교판을 만든다.
3. 방향 단서(얼굴 끝·꼬리)를 눈으로 확인한다.
4. 외곽 크기와 접지선을 잰다.
5. A 기준판에 눈·귀·몸·발을 겹쳐 본다.
6. 꼬리·손·귀 등 분리된 부분이 잘리지 않았는지 확인한다.
7. 톤앤매너 표를 확인한다.
8. 실패 항목이 0개일 때만 라이브러리와 런타임 파일을 갱신한다.
9. 실제 144px 비교판을 사용자에게 보여 준 뒤 깃에 반영한다.

## 6. 즉시 실패 조건

- `↘`와 `↗`이 반대로 읽힘
- 걷는 발 또는 서로 다른 발 크기
- 귀 잘림·귀 크기 변화
- 타입별 눈 크기·눈 위치 차이 2px 초과
- 목표 외곽 범위 이탈
- 몸에서 떨어진 꼬리·손·의상 누락
- 같은 타입 무늬가 단계마다 반대편으로 이동
- 한 타입만 다른 카메라 높이 또는 다른 그림체
