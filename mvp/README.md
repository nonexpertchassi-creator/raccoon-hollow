# 첫 판 (MVP)

**물음은 하나다 — “25분 동안 손이 심심하지 않은가.”**
그것만 확인하려고 만든 판이라 **보석·현금·이벤트는 하나도 없다.**

- 아티팩트: <https://claude.ai/code/artifact/4dc137a2-739e-44ad-b51a-1d8f26c1ad7f>
- 이 폴더의 `index.html`이 그대로 그 아티팩트다. **고치면 다시 밀어야 한다.**

## 들어 있는 것

조선 1구역 네 곳(떡집·국밥집·나물집·생선집) · 손님이 와서 사고 감 ·
제조시간과 공정과 일꾼 · 레벨업과 별과 물건 바뀜 · 자리 비운 만큼 받기 + 주사위 ·
오래 기다린 손님은 화내고 감

## 빠진 것

보석 전부(스킬·뽑기·간판·가로등) · 돈 내는 것 전부 · 이벤트 · 패스 · 광고 ·
도감 · 구역 2~5 · 챕터 2~5 · 2.5D · 그림

## 숫자

**`tools/balnum.py`에서 손으로 옮겨 적었다.** 지금은 그것뿐이라
장부에서 숫자를 고치면 `index.html` 맨 위 `B = {...}`도 같이 고쳐야 한다.
(규칙 3을 어기고 있는 자리다 — 오래 쓸 거면 뽑아 쓰게 고쳐야 한다)

## 무엇을 보나

화면 맨 아래 눈금 넷 — **판 것 · 누른 횟수 · 짜증 % · 초당 냥.**
25분 놀고 나서 이 넷과 “심심했나”를 같이 적어 두면 다음 판을 잴 수 있다.
