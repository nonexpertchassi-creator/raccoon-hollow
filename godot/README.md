# godot/ — 이관 작업방

**경제 규칙 · 마을 화면 · 누르기 · 창 셋 · 저장이 넘어왔다.** 이제 손으로 논다 —
매대를 눌러 강화하고, 나쁜 놈을 잡고, 장을 열고, 창에서 승급·의뢰·도감을 본다.
껐다 켜면 이어지고, 자리를 비운 동안 번 것이 쌓여 있다.

넘어온 것이 맞는지는 눈으로 안 본다. `sim.js`를 답안지로 두고
같은 씨앗으로 양쪽을 돌려 1분마다 대조한다.

## 돌리는 법

```sh
tools/godot-install.sh        # 이 작업방에 Godot을 깐다 (일회용 상자라 세션마다)
node tools/gen-content.mjs    # content.js → rules/content.gd 다시 뽑기
tools/crosscheck.sh           # JS판과 대조 (fmt · rng · content · sim)
SIM_HOURS=4 tools/crosscheck.sh sim   # 길게 돌려 어긋남이 쌓이는지 본다
```

**맥에서 열 때**는 Godot을 켜고 `Import` → 이 `godot` 폴더의 `project.godot`을
고르면 된다. `Play`(▶)를 누르면 마을이 뜬다.

**깃을 Godot 안에서 쓰려면** — Godot Git Plugin(에셋 라이브러리 1581)을 깔고
`Project > Version Control > Version Control Settings`에서 GitPlugin을 고른다.
저장소가 프로젝트 폴더보다 위에 있어도 알아서 찾는다(이 저장소가 그렇다).
다만 이 저장소는 **비공개**라 받으려면 GitHub 개인 토큰(PAT)이 필요하고,
플러그인은 그 토큰을 디스크에 저장하지 않아 켤 때마다 다시 넣어야 한다.

## 왜 이렇게 하는가

엔진을 옮길 때 제일 무서운 건 **조용히 달라지는 것**이다. 반올림 방향 하나만
어긋나도 몇 시간 뒤에 경제가 벌어지는데, 그때는 어디서 갈라졌는지 못 찾는다.

JS판(`sim.js`)은 몇 달간 실제로 돌아갔고 `tools/balance.mjs`로 수백 시간을
재본 코드다. 그러니 정답으로 취급할 수 있다. 옮긴 조각마다 같은 입력을
양쪽에 넣고 대조하면, 어긋난 그 순간에 잡힌다.

### 지금까지의 성적

```
✅ tap      누르기 여섯 가지 다 먹는다
✅ file     파일에 담았다 꺼내도 같다
✅ bits     저장한 소수가 비트까지 그대로다
✅ fmt      5004개 전부 일치      숫자 줄여 쓰기
✅ rng       160개 전부 일치      씨앗 고정 난수 (32비트 정수로 대조)
✅ content   678개 전부 일치      숫자 전부
✅ sim       240개 전부 일치      4시간치를 1분마다 · 씨앗 1·2·3·7
✅ save      30분 뒤까지 안 껐을 때와 똑같다
```

`sim`이 진짜 시험이다. 규칙이 서로를 부르고 결과가 다음 틱의 입력이 되니까,
한 곳만 어긋나도 시간이 갈수록 벌어진다. 1분마다 32가지 값을 통째로 적어
대조하면 **몇 분째에 어느 값부터** 갈라졌는지가 바로 나온다.

### 첫 조각부터 실제로 걸렸다

옮긴 함수가 딱 하나였는데도:

```
입력 5625 · JS 5.63K · Godot 5.62K
```

JS의 `toFixed()`는 절반을 올리고(5.625→5.63), C의 `%.2f`는 짝수 쪽으로
붙인다(→5.62). 코드는 한 줄 한 줄 그대로 옮겨 적은 것이었다. 눈으로는
백 번을 봐도 못 찾는다.

고친 방법은 한쪽을 흉내 내는 게 아니라 **두 언어가 똑같이 할 수 있는 규칙으로
바꾼 것**이다 — 자릿수만큼 곱해 내리고 나누면 찍는 단계에 반올림할 게 안 남는다.

그리고 시험 문제를 고쳤다. 처음엔 난수만 뿌렸더니 한 번은 통과하고 다음엔
실패했다 — 반올림이 갈리는 건 값이 딱 절반에 떨어질 때뿐이라 우연히 걸려야만
드러났기 때문이다. **어쩌다 잡히는 시험은 시험이 아니다.** 지금은 씨앗을
고정하고 절반에 떨어지는 값을 일부러 전부 넣어 5,004개를 돌린다.

## 내 컴퓨터(맥)에 깔 때

이 스크립트는 필요 없다. https://godotengine.org/download 에서
**`Godot Engine`** 을 받는다 — 그 아래 `Godot Engine – .NET`은 C#을 쓸 때만
필요하고 우리는 GDScript라 아니다.

- 받은 zip을 풀면 `Godot.app` 하나가 나온다. 응용 프로그램 폴더로 옮기면 끝이다.
- 처음 열면 맥이 "확인되지 않은 개발자"라고 막는다. **아이콘을 우클릭 → 열기**로
  열거나, 시스템 설정 → 개인정보 보호 및 보안 에서 '그래도 열기'를 누른다.
  한 번만 하면 그다음부터는 그냥 열린다.
- Apple Silicon과 Intel이 한 파일에 다 들어 있다. 고를 것 없다.
- 지울 때는 그 앱 하나만 버리면 된다. 설치 과정이 없으니 남는 것도 없다.

**작업방과 같은 판(4.7.2)을 쓴다.** 판이 다르면 같은 프로젝트를 열었을 때
경고가 뜨거나 미묘하게 다르게 굴 수 있다 — 대조를 무기로 쓰는 마당에
그런 변수는 없는 게 낫다.
