# 그림 두는 곳

뽑은 그림은 **여기에 넣는다.** 클라우드 상자는 언젠가 치워지는데,
저장소에 넣어 두면 안 사라진다. 그리고 **파일이 곧 도감이다** —
지나온 물건을 도감에 남기기로 했으니(장부 · 시나리오 픽스),
400장이 전부 살아 있어야 한다.

## 이름 규칙

```
art/ch1/01-떡집/01-보리떡.png
     │    │        └── 물건 번호 · 이름
     │    └── 매장 번호 · 이름
     └── 챕터 번호
```

**번호가 곧 레벨 순서다.** 그래서 파일 이름으로 정렬하면 진열 순서가 그대로 나온다.
`01-보리떡`은 1~50레벨, `20-약과`는 951~1,000레벨.

번호는 **두 자리로 적는다.** `1-보리떡`이라고 하면 `1`, `10`, `11`, `2` 순으로
정렬돼서 순서가 뒤집힌다.

## 그림 규칙

| | |
|---|---|
| **배경** | **투명하게.** 매대 위에 올려야 해서 크림색이 칠해져 있으면 못 쓴다 |
| **크기** | 한 챕터 안에서 같게. 나중에 줄이는 건 되지만 늘리면 뭉갠다 |
| **각도** | 위에서 비스듬히 — 첫 12장에서 잡힌 그 각도 |

**같은 매장 안에서 모양이 겹치지 않게 한다.** 첫 12장에서 국밥집의
보리밥과 배춧국이 똑같은 갈색 뚝배기로 나왔다. 안이 달라도 멀리서는 같은 그릇이다.
**그릇을 돌려 쓴다** — 뚝배기 · 사발 · 대접 · 접시 · 소반.

### 물건 아트 기준 — Decision 2026-09-02

물건은 크게 확대해서 감상하는 삽화가 아니라, 작은 모바일 화면에서 빠르게 알아보는
게임 아이콘이다. **사실적인 묘사보다 단순한 형태와 실루엣을 먼저 지킨다.**

1. 큰 형태 하나와 물건을 구분하는 대표 특징 1~3개만 먼저 남긴다.
2. 한 물건의 주조색은 밝기 기준 **최소 2단계, 최대 4단계** 안에서 표현한다.
3. 광고·도감용 고밀도 일러스트처럼 매끈하고 화려하게 렌더링하지 않는다.
4. 색이 부드럽게 번지고 겹치는 **담백한 수채화 느낌**을 사용한다. 종이 배경은 넣지 않는다.
5. 나뭇결·직조·도자기·음식 표면 등 재질은 구분에 필요한 만큼만 표현하고 반복 무늬를 빽빽하게 넣지 않는다.
6. `64~96px`로 축소해도 이름을 보지 않고 물건의 종류가 읽혀야 한다.
7. 같은 매장 안에서는 시점, 캔버스 점유율, 외곽선 굵기를 통일한다.
8. 내부 선보다 실루엣을 우선하고, 내부 선이 축소 화면에서 뭉치면 삭제한다.

검수 순서는 `실루엣 → 같은 매장 내 구분 → 명암 단계 → 수채화 느낌 → 재질`이다.
재질 묘사가 실루엣이나 작은 화면 가독성을 해치면 재질을 줄인다.

### 매장 20번 프리미엄 규칙 — Decision 2026-09-02

각 매장의 `20번`은 1,000레벨에서 만나는 마지막 물건이므로 반드시 프리미엄으로 보이게 만든다.

- 프리미엄은 세부 묘사의 양보다 더 큰 존재감, 안정적인 구성, 정돈된 배치로 표현한다.
- 금박, 옻칠 받침, 고급 포장, 자수처럼 품목에 맞는 고급 단서를 1~2개만 사용한다.
- 일반 물건보다 포인트 대비는 높일 수 있지만, 단순화·수채화·명암 2~4단계 규칙은 유지한다.
- 장식 때문에 물건의 정체가 흐려지거나 `96px`에서 뭉치면 장식을 줄인다.
- 같은 매장의 앞선 19개보다 한 단계 귀하고 완성된 물건으로 읽혀야 한다.
