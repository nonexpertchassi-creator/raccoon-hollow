# 그림 두는 곳

뽑은 그림은 **여기에 넣는다.** 클라우드 상자는 언젠가 치워지는데,
저장소에 넣어 두면 안 사라진다. 그리고 **파일이 곧 도감이다** —
지나온 물건을 도감에 남기기로 했으니(장부 · 시나리오 픽스),
400장이 전부 살아 있어야 한다.

## 이름 규칙

```
art/ch1/01-떡집/01-보리떡.png
     │    │        └── 물건 번호 · 이름
     │    └── 매장 번호 · 이름
     └── 챕터 번호
```

**챕터 5개가 다 잡혀 있다.** 폴더 100개(매장) · 물건 2,000개.

| | | |
|---|---|---|
| `ch1` | 한국 조선 | **유저가 한 줄씩 훑었다** |
| `ch2` | 미국 서부 | 초안 |
| `ch3` | 그리스 고대 | 초안 |
| `ch4` | 멕시코 | 초안 |
| `ch5` | 일본 에도 | 초안 |

초안은 **아직 아무도 안 본 것**이다. 그리기 전에 한 번 훑는 게 싸다.

**번호가 곧 레벨 순서다.** 그래서 파일 이름으로 정렬하면 진열 순서가 그대로 나온다.
`01-보리떡`은 1~50레벨, `20-약과`는 951~1,000레벨.

번호는 **두 자리로 적는다.** `1-보리떡`이라고 하면 `1`, `10`, `11`, `2` 순으로
정렬돼서 순서가 뒤집힌다.

## 그림 규칙

| | |
|---|---|
| **배경** | **투명하게.** 도감 칸과 매장 카드에 올려야 해서 크림색이 칠해져 있으면 못 쓴다 |
| **크기** | 한 챕터 안에서 같게. 나중에 줄이는 건 되지만 늘리면 뭉갠다 |
| **각도** | 위에서 비스듬히 — 첫 12장에서 잡힌 그 각도. **바꿀 일 없다**(아래) |

### 물건은 2.5D로 안 그린다

게임 무대는 2.5D지만 **물건 그림이 올라가는 곳은 도감 칸과 매장 카드뿐**이고
그 둘은 평면이다. 판매대 위 물건은 **레벨이 올라도 안 바뀌기로 했다**
(장부 · UX·UI 픽스). 그래서 **지금 뽑고 있는 각도 그대로** 400장을 다 뽑으면 된다.

2.5D로 그릴 것은 **매장 건물과 오브제**뿐이고, 그건 이 목록에 없다.

## 챕터끼리 이름이 겹치는 것이 있다

연장과 재료는 어느 나라에나 있어서 **일부러 안 바꿨다** — 삽·낫·도끼·망치·쇠못.
`ch1`의 삽과 `ch2`의 삽은 **이름은 같아도 다른 그림**이다. 폴더가 다르니 파일도 안 부딪힌다.
**같은 그림을 돌려 쓰지 마라** — 조선의 삽과 서부의 삽은 자루도 날도 다르다.

**같은 매장 안에서 모양이 겹치지 않게 한다.** 첫 12장에서 국밥집의
보리밥과 배춧국이 똑같은 갈색 뚝배기로 나왔다. 안이 달라도 멀리서는 같은 그릇이다.
**그릇을 돌려 쓴다** — 뚝배기 · 사발 · 대접 · 접시 · 소반.

## 코드는 이 폴더를 안 건드린다

그림과 코드는 **서로 다른 파일**만 만진다(`CLAUDE.md`).
코드가 이 폴더 안의 파일 내용을 고치는 일은 없다.
