# 너구리 만물상

너구리가 주워온 잡동사니를 씻어서 마을에 오는 동물들에게 파는 방치형 타이쿤.

## 왜 이 소재인가

너구리는 원래 **주워오고 씻는** 동물이다. 만물상은 **주워온 걸 파는** 가게다.
소재와 메커니즘이 필연적으로 붙는다 — 기존 너구리 게임들(빵공장, 가구공방)에는 없는 부분이다.

그리고 씻는 단계가 게임의 병목이 된다. 주워오는 속도보다 씻는 속도가 느리면 재고가
쌓이고, 그러면 빨래통을 늘려야 한다. 방치형이 필요로 하는 병목이 소재에서 저절로 나온다.

## 구조

```
줍기 → (창고) → 씻기 → (진열대) → 판매 → 업그레이드 → 새 동물 해금
```

**동물이 곧 스테이지다.** 새 동물이 마을에 오는 게 진행이고, 그 동물이 원하는 등급이
새로 열리는 콘텐츠고, 동물 도감이 컬렉션이 된다. 진행·해금·수집이 한 덩어리다.

아직 살 동물이 없는 보물은 창고에 그대로 쌓인다. 그리고 곰이 오는 순간 그게 전부 돈이 된다.

## 파일

```
content.js   내용물 전부 — 잡동사니·동물·업그레이드·이사 수치
sim.js       경제 로직. 그리기 코드가 한 줄도 없다
tools/       balance.mjs — 브라우저 없이 게임 수백 시간을 몇 초에 돌린다
core/        shipyard에서 가져온 저장·계측·주스 레이어
```

로직과 렌더링을 분리한 이유: **방치형은 성장 곡선이 곧 게임이다.**
브라우저를 띄워야만 확인이 되면 하루에 몇 번 못 돌려본다.

## 밸런싱

```bash
node tools/balance.mjs 6     # 6시간 연속 플레이를 몇 초에
node tools/balance.mjs 1     # 신규 유저의 첫 1시간
```

숫자만 바꿔가며 수백 번 돌려본 뒤에 그림을 그린다. 반대로 하면 되돌릴 수 없다.
