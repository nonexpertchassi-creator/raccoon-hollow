# 라쿤 마켓

너구리가 온갖 것을 파는 가게를 키우는 방치형 게임. 2.5D 아이소메트릭, 세로 화면.

**2026-08-31에 새로 시작했다.** 이 한 줄 말고는 아직 정해진 것이 없다 —
무대도, 가게도, 물건도, 손님도.

## 여기에 무엇이 있나

| | |
|---|---|
| `CLAUDE.md` | **작업 규칙.** 여기부터 읽는다 |
| `FORMULAS.md` | **살려 둔 계산법.** 이름이 하나도 없어서 무대가 바뀌어도 그대로 쓴다 |
| `PLAN.md` | **배운 것 열둘.** 다시 밟을 함정만 |
| `REFS.md` | 다른 게임에서 본 것 |
| `RACCOON.md` | 너구리 그림 지침 |

**기획은 장부(아티팩트)에 쓴다.**

## 옛 판

`godot/` · `content.js` · `sim.js` · `iso.js` · `tools/`는 **옛 판**이다.
조선풍 컨셉으로 만들었고, 지우지 않았지만 **참고하지 않는다.**
살릴 것은 `FORMULAS.md`로 이미 옮겼다.

옛 문서(시놉시스 · 용어집 · 도감 · 그림 주문서 등)는 지웠다 —
전부 깃에 있다: `git log --diff-filter=D --name-only`
